# Architecture Decision Records (ADRs)

Every change to a shared contract (see `/packages/schemas/`) needs a short ADR here before merge.

## Template

```
# ADR-00X: <title>

Date:
Author:
Status: Proposed / Accepted / Superseded

## Context
Why is this change needed?

## Decision
What are we changing?

## Consequences
Who does this affect (which modules/members)? What breaks if not updated?
```
